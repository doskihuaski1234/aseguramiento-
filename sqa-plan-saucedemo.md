# SQA Plan — Sauce Demo

## 1. Propósito

Verificar que las funciones principales del inventario y la navegación de Sauce Demo funcionen correctamente y de forma consistente mediante pruebas automatizadas.

## 2. Alcance

Se prueban el inventario, productos, precios, carrito, navegación, menú y cierre de sesión. No se prueba el flujo completo de checkout ni los pagos.

## 3. Herramientas

Se utiliza **Playwright** para la automatización de pruebas y **TypeScript** como lenguaje de implementación.

## 4. Criterios de salida

El proyecto se considera listo cuando todas las pruebas definidas se ejecutan correctamente, sin fallos bloqueantes, y la suite automatizada queda aprobada.
